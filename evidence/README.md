# 可核查的交付证据

`unit-tests.tap` 为最后一次 63 项测试输出；`browser-results.json` 为最后一次 107 项浏览器检查；`build-log.txt`、`http-results.json` 为构建与服务器检查；`release-validation.json` 记录干净目录解压重建。

`balance-results.json`：450 次普通模式（六类策略，各 75 个种子）。`extended-simulation.json`：每日逻辑和无尽模式各 75 个种子。同种子跨模式复用，不是独立用户样本。飞行时长不是完整真人局时长。

`review1-*` 和 `first-*` 是较早迭代的留档，不能与最终版本数值混用。`review2-browser-results.json` 是后一轮修改前的浏览器通过记录。`idea-scores.json` 是主观立项评分。

主页／早期场地／改装截图来自真实浏览器运行。`late-game-mobile.png`、`result-mobile.png` 与 `example-score-card.png` 来源于鼠标输入驱动、物理等待被加速的测试对局。`stress-mobile.png` 是特意注入的满负载场景，不是普通开场或真人成绩。`preview.png` 只拼接本项目实际界面截图。

这些素材可以帮助检查交付，不应作为虚构“玩家已达到某个成绩”“真实平均五秒通关”或“中端手机一定 60 FPS”的广告证据。
