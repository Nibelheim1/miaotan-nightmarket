# TapTap 发行边界与适配计划

本版是标准浏览器游戏，不是已发布的 TapTap 游戏。没有访问用户开发者账号，没有申请资质、创建支付／广告位或上传到公共平台。`PlatformService.capabilities` 的远程功能全部为 false；`submitScore` 返回 `LOCAL_ONLY`，不会伪造提交成功。

## 确认过的公开入口

TapTap 官方游戏测试公告说明 H5／制造作品可在开发者中心建立上线前测试计划：https://www.taptap.cn/moment/839175490559282632 。实际计划开放状态、账号角色与版本资格由登录后的后台决定。

官方 H5 开放能力资料在 https://github.com/taptap/instant-games-open-mcp 。其中包含 H5 发布和多种开放能力，但这是**开发工具／API 能力说明**，不是本游戏已经内置这些 SDK 的证据。特别不要将 Maker MCP 与小游戏／H5 广告能力混用。

历史 PC 包体说明 https://www.taptap.cn/moment/598609424361196724 与通用 H5 上传入口可能不同。本包没有根据旧文自作主张开启 gzip 或套用其他平台的包体限制。

## 当前适配点

| 模块 | 已实现 | 真实接入前要做 |
|---|---|---|
| PlatformService | 本地初始化、能力声明 | 根据当前官方示例构建实际桥接，初始化失败回退 |
| StorageService | 校验过的 LocalStorage + 内存兜底 | 确认云存档冲突规则、账号切换与迁移，不直接覆盖 |
| LeaderboardService | 最多 30 条本机历史，按模式筛选展示 | 申请实际榜 ID；区分模式、版本和日期；防作弊不能信任客户端分数 |
| ShareService | Canvas PNG、文件导出、可用时系统分享 | 平台容器里校验文件分享能力、回退保存图片 |
| AnalyticsService | 内存事件环、手动 JSON 导出 | 真实同意流程和接收端，不默认发送个人数据 |
| 广告／支付 | 未加入 | 先验证自然重玩；不要为填接口植入假按钮或硬编码密钥 |

## 发布顺序

本地 HTTP 真机测试 → 建立 H5 测试版本并上传生产入口 → 核对竖屏、资源 MIME、浏览器权限和生命周期 → 小范围招募观察 → 修正阻塞和核心体验 → 再决定正式发布。

游戏主体、身份和商业化条件、审核、隐私政策、适龄提示、权利文件等须以当时平台要求和适用规则核验。本项目不以未经核实的“个人免资质”替代这一步，也不承诺必过审。

生产包无外部域名依赖、无远程字体、无实时后端。加入任何平台 SDK 后都必须重新构建、离线回退测试、流量审计及版本留档。不要把开发者 OAuth 或 API 密钥写入客户端。
