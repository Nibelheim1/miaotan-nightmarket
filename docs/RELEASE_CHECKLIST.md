# 上线前验收

以下是尚待发布者在真实环境执行的核对项，不是本次已完成清单。

- [ ] 最新 Android Chrome 和至少一种目标 TapTap WebView 真机；低／中端机长玩与发热。
- [ ] iPhone Safari 真机的手势、Safe Area、地址栏收缩、声音首次解锁、切后台与回来。
- [ ] 生产 HTTPS 网址，首次打开、刷新、第二次打开和浏览器重启后的原生 LocalStorage；不同版本存档迁移。
- [ ] 系统分享不可用时能保存 PNG；取消分享不报错；聊天应用内浏览器的降级提示。
- [ ] 当前开发者后台对 H5 的账号角色、主体要求、压缩包目录、隐私和权利材料。
- [ ] 游戏名称和素材权利复核；不在商店页写“必爆”“全球第 X”或虚构留存。
- [ ] 按 MARKET_RESEARCH.md 的首测计划观察新玩家，记录完成率／二局率／时长分布。
- [ ] 正式商店图与视频来自真实游玩，压力测试和 debug 截图不能冒充普通首局。

## 已知设计边界

只有本机排行榜；客户端种子与存档可被修改，没有在线反作弊。刷新回到本轮发射前允许重试，因此不能将分数直接用作现金或付费奖励依据。

普通模式对随机瞄准代理仍较宽容；正式新手胜率未测。无尽模式有额外压力，但没有证明所有构筑或所有种子平衡。小高度横屏仅为应急兼容，竖屏为主。

这是 Web 完整可玩版本，不含原生 APK／iOS 安装包、微信小游戏工程、后台、云存档或 SDK 商业化模块。
